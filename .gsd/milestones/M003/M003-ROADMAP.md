# M003: 

## Vision
사용자가 앱을 처음 켰을 때 "잘 만든 앱"이라는 인상을 받을 수 있도록, 시각적 완성도와 인터랙션 품질을 끌어올린다. 삭제 기능을 완성하고, 어색한 상태 표시를 자연스러운 로딩 UX로 교체하며, 탭 바 아이콘·뒤로가기·전체 레이아웃을 세련되게 다듬는다.

## Slice Overview
| ID | Slice | Risk | Depends | Done | After this |
|----|-------|------|---------|------|------------|
| S01 | 네비게이션 UI 개선 (탭 아이콘·뒤로가기) | low | — | ✅ | 탭 바에 아이콘이 보이고, 주제 상세에서 뒤로가기가 깔끔하게 동작한다. |
| S02 | 제출 로딩 UX 개선 | low | S01 | ✅ | 제출 버튼을 누르면 로딩이 표시되고, 완료 시 자연스럽게 평가 결과 화면으로 전환된다. |
| S03 | 삭제 기능 완성 | medium | S01 | ⬜ | 이력 목록에서 항목을 스와이프하거나 버튼을 탭해 삭제하면 목록에서 사라진다. |
| S04 | 전체 UI 디자인 개선 | medium | S02, S03 | ⬜ | 앱 전체 화면을 스크롤해봤을 때 일관된 디자인이 느껴진다. |
