# S01: 디자인 토큰 + 공통 컴포넌트 + 전체 화면 리디자인 — UAT

**Milestone:** M004
**Written:** 2026-04-01T07:46:09.583Z

## 전제 조건

- `cd mobile && npx expo start` 로 Expo 개발 서버 실행 중
- iOS 시뮬레이터 또는 Android 에뮬레이터 또는 Expo Go 앱으로 접속
- 백엔드 서버 실행 중 (`docker compose up`)
- 최소 1개 이상의 주제(prompt)가 DB에 존재

---

## TC-01: 앱 전체 배경색 — Indigo 오프화이트 적용 확인

**목적:** 모든 화면에서 배경색이 #F8F7FF(Indigo 틴트 오프화이트)로 표시되는지 확인

1. 앱을 실행한다.
2. 주제 목록 화면(홈 탭)을 연다.
3. **기대:** 화면 배경이 순백(#FFFFFF)이 아닌 연보라빛 오프화이트(#F8F7FF)로 표시된다.
4. 다른 탭(히스토리)으로 이동한다.
5. **기대:** 히스토리 탭 배경도 동일한 오프화이트로 표시된다.

---

## TC-02: 주제 목록 화면 — Indigo 카드 스타일 확인

**목적:** 주제 목록 카드가 Indigo 테마(그림자, radius, 색상 토큰)로 표시되는지 확인

1. 홈 탭을 연다.
2. 주제 카드 목록을 확인한다.
3. **기대:**
   - 카드에 Indigo 계열 그림자(보라빛 음영)가 적용된다.
   - 카드 배경이 surface 흰색이다.
   - 카테고리/난이도 Badge가 Indigo primary 색상으로 표시된다.
4. 아래로 스크롤한다.
5. **기대:** 스크롤 중 화면 배경이 오프화이트로 유지된다(#FFFFFF 흰색 배경 노출 없음).

---

## TC-03: 주제 상세 화면 — description 카드 UI 확인

**목적:** description이 surfaceElevated 카드 안에 표시되는지 확인

1. 홈 탭에서 주제 하나를 탭한다.
2. 주제 상세 화면으로 이동한다.
3. **기대:**
   - 주제 제목이 큰 타이포그래피로 표시된다.
   - 주제 설명(description)이 '주제 설명' 레이블과 함께 카드 박스 안에 표시된다.
   - '작성 시작' 버튼이 primary(Indigo) 배경으로 표시된다.
4. 기존 draft가 있는 경우: '이어서 작성' 버튼이 primaryDark(짙은 Indigo)로 표시된다.
5. **기대:** 두 버튼이 시각적으로 구분되는 Indigo 색조를 가진다.

---

## TC-04: 답안 작성 화면 — 하드코딩 색상 제거 확인

**목적:** write/index.tsx에서 Indigo 테마가 올바르게 적용되는지 확인

1. 주제 상세 화면에서 '작성 시작'을 탭한다.
2. 답안 작성 화면이 열린다.
3. **기대:**
   - 화면 배경이 Indigo 오프화이트이다.
   - 텍스트 입력 영역이 surface 배경이다.
   - 하단 footer에 미묘한 그림자(shadow.bar)가 있다.
4. draft 상태에서 이 화면을 열 경우: 상태 배너가 주황/노란 배경(warningLight) + 좌측 3px warning 보더로 표시된다.
5. **기대:** 기존 주황 하드코딩(#FFF3E0, #E65100)이 아닌 테마 토큰 기반 색상이다.

---

## TC-05: 평가 결과 화면 — 점수 구간별 색상 확인

**목적:** evaluation/[submissionId].tsx의 총점 카드가 점수에 따라 색상이 달라지는지 확인

1. 답안을 작성하고 제출(평가)한다.
2. 평가 결과 화면이 열린다.
3. **기대 (점수 8-10점):** 총점 카드 배경이 초록빛(successLight)이다.
4. **기대 (점수 5-7점):** 총점 카드 배경이 노란빛(warningLight)이다.
5. **기대 (점수 1-4점):** 총점 카드 배경이 붉은빛(dangerLight)이다.
6. 피드백 카드를 확인한다.
7. **기대:** 피드백 카드 배경이 primarySurface(연한 Indigo)이다.
8. ScoreBar 4개가 Indigo 기반 그라데이션(또는 광택 오버레이) 효과로 표시된다.

---

## TC-06: 히스토리 탭 — 삭제 버튼 색상 확인

**목적:** history.tsx의 삭제 버튼이 danger 토큰으로 표시되는지 확인

1. 히스토리 탭으로 이동한다.
2. 제출 항목이 있는 경우, 스와이프하여 삭제 버튼을 표시한다.
3. **기대:** 삭제 버튼 배경이 colors.danger(#C62828 짙은 빨강)이다(기존 #F44336 밝은 빨강이 아님).
4. 로딩 중인 경우 ActivityIndicator가 표시된다.
5. **기대:** ActivityIndicator 색상이 colors.primary(Indigo #5C6BC0)이다(기존 #2196F3 파란색이 아님).

---

## TC-07: 헤더 및 탭바 스타일 확인

**목적:** 레이아웃 컴포넌트가 Indigo 테마로 표시되는지 확인

1. 앱 상단 헤더를 확인한다.
2. **기대:** 헤더 배경이 흰색(surface)이며 Indigo 계열 하단 그림자(shadow.bar)가 표시된다.
3. 하단 탭바를 확인한다.
4. **기대:** 탭바가 충분한 높이(iOS: 84px, Android: 60px)로 표시된다.
5. 활성 탭 아이콘/텍스트가 Indigo primary 색상으로 표시된다.

---

## TC-08: 공통 컴포넌트 — LoadingView / ErrorView 확인

**목적:** 공통 컴포넌트가 새 테마로 표시되는지 확인

1. 네트워크를 차단하거나 잘못된 URL을 시뮬레이션하여 ErrorView를 트리거한다.
2. **기대:** ErrorView가 shadow.card 카드 레이아웃 + 원형 아이콘 배지로 표시된다(기존 단순 텍스트 에러가 아님).
3. 데이터 로딩 중 LoadingView를 확인한다.
4. **기대:** LoadingView가 카드 스타일로 표시되며 ActivityIndicator 색상이 Indigo primary이다.
