# S04 UAT: 모바일 클라이언트

## 전제 조건
- Docker Compose로 서버+DB가 기동된 상태 (`docker compose up`)
- 마이그레이션 및 시드 데이터 적용 완료
- Expo 앱이 `npx expo start`로 실행 중
- `mobile/.env`에 `EXPO_PUBLIC_API_URL=http://localhost:3100` 설정됨

---

## TC-01: 앱 최초 실행 시 사용자 ID 생성

**Steps:**
1. AsyncStorage를 초기화(앱 재설치 또는 데이터 삭제)
2. 앱을 실행한다

**Expected:**
- 앱이 로딩 화면을 잠시 표시한 후 주제 목록 탭이 보인다
- 내부적으로 UUID가 생성되어 AsyncStorage에 저장된다
- 이후 앱 재실행 시 동일한 UUID가 사용된다

---

## TC-02: 주제 목록 조회

**Steps:**
1. 앱을 실행하여 '주제' 탭(기본 탭)에 진입한다

**Expected:**
- 서버에서 주제 목록이 로드되어 FlatList로 표시된다
- 각 주제에 카테고리 뱃지(예: 일상, 사회)와 난이도 뱃지(초급/중급/고급)가 표시된다
- 로딩 중에는 ActivityIndicator가 보인다

**Edge Case — 서버 미기동:**
- 에러 메시지가 표시된다 (네트워크 오류)

---

## TC-03: 주제 상세 보기 및 작성 시작

**Steps:**
1. 주제 목록에서 주제 하나를 탭한다
2. 주제 상세 화면에서 제목, 설명, 카테고리, 난이도를 확인한다
3. '작성 시작' 버튼을 탭한다

**Expected:**
- 주제 상세 화면에 제목, 설명, 카테고리, 난이도가 표시된다
- '작성 시작' 탭 시 POST /submissions가 호출되어 새 답안이 생성된다
- 답안 작성 화면(write/[submissionId])으로 자동 이동한다

---

## TC-04: 답안 작성 및 임시저장

**Steps:**
1. TC-03에서 이동한 답안 작성 화면에서 텍스트를 입력한다
2. '임시저장' 버튼을 탭한다
3. 앱을 종료하고 다시 같은 주제에서 '작성 시작'이 아닌 기존 draft를 이어서 연다

**Expected:**
- TextInput(multiline)에 텍스트를 입력할 수 있다
- 임시저장 시 PATCH /submissions/:id가 호출되고 성공 피드백이 표시된다
- 기존 draft를 다시 열면 이전에 저장한 내용이 표시된다

---

## TC-05: 답안 제출 및 AI 평가

**Steps:**
1. 답안 작성 화면에서 충분한 텍스트를 입력한다 (최소 10자 이상)
2. '제출' 버튼을 탭한다

**Expected:**
- 제출 중 로딩 UI가 표시된다
- 미저장 변경사항이 있으면 자동 저장 후 제출된다
- PATCH /submissions/:id/submit → POST /submissions/:id/evaluate가 순차 호출된다
- 평가 완료 후 evaluation/[submissionId] 화면으로 자동 이동한다

**Edge Case — 빈 텍스트 제출:**
- 서버에서 400 에러가 반환되고 Alert로 에러 메시지가 표시된다

---

## TC-06: 평가 결과 확인

**Steps:**
1. TC-05에서 자동 이동한 평가 결과 화면을 확인한다

**Expected:**
- 총점이 강조 표시된다
- 문법, 논리, 표현력, 주제 적절성 4항목의 점수가 프로그레스 바로 표시된다
- 각 항목의 feedback 텍스트가 표시된다
- 로딩 중 ActivityIndicator가 표시된다

---

## TC-07: 이력 목록 조회

**Steps:**
1. 하단 탭에서 '이력' 탭을 탭한다

**Expected:**
- GET /evaluations/history가 호출되어 FlatList로 이력이 표시된다
- 각 항목에 주제 제목, 총점, 날짜가 표시된다
- 상단에 점수 추이 섹션이 표시된다 (미니 바 형태)
- 이력 항목을 탭하면 해당 평가 결과 화면으로 이동한다

**Edge Case — 이력 없음:**
- '평가 이력이 없습니다' 같은 빈 상태 메시지가 표시된다

---

## TC-08: 점수 추이 확인

**Steps:**
1. '이력' 탭에서 상단의 점수 추이 섹션을 확인한다

**Expected:**
- GET /evaluations/scores/trend가 호출된다
- 최근 평가들의 총점 추이가 수평 미니 바로 표시된다
- 데이터가 없으면 추이 섹션이 숨겨진다

---

## TC-09: 전체 E2E 흐름

**Steps:**
1. 앱 실행 → '주제' 탭에서 주제 선택
2. 주제 상세에서 '작성 시작'
3. 답안 작성 → '임시저장' → 추가 작성 → '제출'
4. 평가 결과 화면에서 점수/피드백 확인
5. '이력' 탭으로 이동하여 방금 제출한 이력 확인
6. 이력 항목 탭하여 평가 결과 다시 확인

**Expected:**
- 1~6 전체 흐름이 에러 없이 완료된다
- 각 화면 전환이 자연스럽다
- 데이터가 서버와 동기화되어 있다
